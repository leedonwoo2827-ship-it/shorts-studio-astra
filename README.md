# 쇼츠공방 II

**단행본 한 장(章)을 넣으면, 화면이 실제로 움직이는 세로 쇼츠가 나옵니다.**

```
1장.pdf   →   24초 · 1080×1920 · mp4
```

정지 그림에 확대·축소를 준 것이 아닙니다. **GPT-6 Astra 가 씬마다 애니메이션
SVG 를 코드로 씁니다.** 우편 자루가 하나씩 쌓이고, 문이 열리고, 사람들이 돌아섭니다.

> **API 키가 필요 없습니다.** 구독 로그인 두 개만 씁니다 —
> 대본은 **Claude Code**, 장면은 **ChatGPT(Codex)**.

---

## 어떻게 도나

```
  ┌ 대본 만들기 ────────────────────────────────┐
  │  재료      PDF 에서 쪽번호·머리글을 걷어낸다    │
  │  대본    $ 씬 분할 · 후크 · 자막 · 해시태그     │
  │  발음      1840년 → 천팔백사십 년              │
  │  음성      실측 길이가 씬 길이를 정한다          │
  │  자막      SRT + 큐                          │
  │  장면지시 $ 무엇이 어떻게 움직이는가            │
  └───────────────────────────────────────────┘
  ┌ 영상 만들기 ────────────────────────────────┐
  │  장면 제작 $ 아스트라가 SVG 를 쓴다 (씬당 2분반) │
  └───────────────────────────────────────────┘
  ┌ 전체 빌드 ──────────────────────────────────┐
  │  미리보기   굽기 전에 재생해 보고 승인          │
  │  빌드      헤드리스 Chrome 이 프레임을 캡처     │
  └───────────────────────────────────────────┘
       결과   $ 유튜브 제목·설명·태그·고정댓글
```

`$` 네 곳만 크레딧을 씁니다. **묶음 단추는 편의고, 단계는 하나씩 눌러도 됩니다** —
대본은 읽고 고쳐야 하고 장면은 보고 다시 받아야 하니까요.

### 한 편에 드는 것

| | |
|---|---|
| Claude (대본·발음지시·올릴글) | **약 $0.8** |
| Astra (장면 4개) | **4 메시지** · 약 10분 |
| 렌더 | 약 50초 · 크레딧 0 |
| 결과 | 24초 · 1080×1920 · 30fps |

장면은 지시가 바뀐 씬만 다시 받습니다. 자막만 고쳐 다시 구우면 **50초**면 끝납니다.

## 화면

```
┌──────────────────┐
│ 1840년, 소포 하나가 │  ← 위 띠. 후크 2줄 (잉크 / 주황)
│ 학교가 되었다      │     + 진행 레일
├──────────────────┤
│                  │
│   움직이는 장면    │  ← 아스트라가 쓴 SVG. 여기가 움직인다
│   (인라인 SVG)     │
│                  │
├──────────────────┤
│ 학교는 캠퍼스가     │  ← 아래 띠. 음성 자막
│ 없었습니다         │     + #해시태그
```

**장면에는 글자가 없습니다.** 글자는 전부 화면 위에 얹는 층이라, 오타 수정도
모션도 다국어도 공짜입니다. 그림에 글자를 구우면 고칠 수도 움직일 수도 없습니다.

## 배치 파일 셋

| | |
|---|---|
| `setup.bat` | 처음 한 번 |
| `run.bat` | 내 PC — **전부 됩니다.** 127.0.0.1 전용 |
| `lan-run.bat` | 사내 공유 — **보기만 됩니다** |

`lan-run.bat` 이 읽기 전용인 것은 협상 대상이 아닙니다. 만드는 단계는 이 PC
주인의 구독으로 돕니다. 남의 요청을 내 구독으로 대신 돌리는 것은 약관이 금지하고,
그래서 서버가 루프백 아닌 곳의 쓰기 요청을 **서버 쪽에서** 403 으로 막습니다 —
버튼을 숨기는 것이 아닙니다.

명령줄이 필요하면 `tools\cli.bat` 에 있습니다. 화면과 **같은 코드**를 부릅니다.

## 설정 — 자주 만지는 것만

`config.json` 이 기본값, `config.local.json` 이 이 PC 것(gitignore)입니다.

| | 기본 | |
|---|---|---|
| `shorts.cuts` | `4` | 씬 수. 한 씬이 한 걸음만 보여 주니 그림이 바뀌면 씬을 늘립니다 |
| `shorts.seconds` | `24` | 목표 길이 (20~24초) |
| `narration.chars_per_sec` | `6.51` | **엔진마다 다른 실측치** — 아래 참고 |
| `art.model` | `gpt-6-astra` | 가벼운 시험은 `gpt-5.6-sol` 로 |
| `art.style_refs` | `assets/style_ref/` | 아스트라에게 **보여 주는** 화풍 기준 그림 |

### 낭독 속도를 다시 재는 법 (엔진·목소리를 바꿨다면 필수)

틀리면 24초짜리가 18초나 30초로 나옵니다.

```
한 편 굽고 → 「음성」 로그의 합계 초를 본다
cps = (자막 글자 수 합) ÷ (합계 초 × speed)
```

지금 값은 edge / `ko-KR-SunHiNeural` 실측입니다 — 184자 → 23.54초(1.2배속) → `6.51`.

## 왜 이렇게 만들었나

### 장면은 한 방향으로 한 번만 움직인다

처음엔 `repeatCount="indefinite"` 로 무한 반복시켰습니다. 그랬더니 아스트라가
이음새가 안 보이도록 **처음 값으로 되돌아오는** 동작을 썼고, 화면이 8초 내내
안절부절못했습니다.

지금은 한 방향으로 한 번 가서 **그 자리에 멈춥니다.** 되돌아오는 `values` 는
검사기가 잡아 다시 시키고, 되풀이를 뜻하는 말(「주기」「흔들」「되돌아」)이 지시에
섞이면 그 단계에서 한 번 더 물어봅니다. 마지막 씬은 동작 창을 60% 만 줘서,
**정지한 화면 위로 마무리 말이 얹힙니다.**

### 그림이 바뀌어야 하면 씬을 늘린다

한 씬 안에서 장면이 다른 장면으로 바뀌면 그건 컷이고, 컷은 씬이 하는 일입니다.

### 인증 두 개를 코드로 잇지 않는다

Claude 와 ChatGPT 를 한 프로세스에 섞지 않습니다. 장면 단계는 **별도
서브프로세스**에서 돌고, 각자 자기 자격증명만 읽습니다. 부르기 전에 상대편
API 키 환경변수를 빈 값으로 덮습니다 — 오래된 `export` 가 구독 대신 키로 나가면
모르는 사이에 과금됩니다.

## 안 하는 것

- **업로드를 하지 않습니다.** 올릴 글까지 만들고 멈춥니다.
- **LAN 에서 만들기를 열지 않습니다.**
- **API 키를 쓰지 않습니다.**
- **대본이 예산을 넘어도 자르지 않습니다** — 말을 잘라 붙이면 문장이 깨지고,
  깨진 문장은 TTS 에서 더 이상하게 들립니다. 경고만 남기고 사람에게 넘깁니다.

## 막혔을 때

| 증상 | 볼 곳 |
|---|---|
| 장면 단계가 바로 실패 | 좌측 레일 아래 **ChatGPT** 칩 → `codex login` |
| `requires a newer version of Codex` | `npm i -g @openai/codex@latest` |
| 대본 단계가 실패 | **Claude** 칩 → 터미널에서 `claude` 한 번 |
| 렌더 실패 | `tools\cli.bat` → `D` (doctor). Chrome·FFmpeg·Node 줄만 보면 됩니다 |
| 24초가 아니라 18초 | `narration.chars_per_sec` 재측정 |
| 후크 글자가 잘림 | 후크 한 줄은 12자입니다 |

### 다시 밟지 말 것 — 실측으로 배운 것

레포 안에서 자동으로 검사합니다: `python tools/lint_repo.py`

- **여러 SVG 를 한 문서에 심으면 `id` 가 충돌한다.** 아스트라가 쓴 네 장면이 전부
  `id="scene"` 을 썼고, `url(#scene)` 이 모두 첫 번째로 붙어 **뒤 씬이 통째로
  비었다.** 오류도 경고도 없었다. → 씬마다 접두어를 붙인다.
- **SMIL 은 문서 시계다.** 씬 2 가 7.9초에 떠도 그 애니메이션은 0초부터 돌고
  있다. → 씬 등장 시각에 위상을 맞춘다.
- **GSAP `drawSVG` 는 유료 플러그인이다.** 무료 빌드에 없고, 없으면 예외도 없이
  아무 일도 안 한다. → dash 로 긋는다.
- **폰트 서브셋 `--unicodes` 에 `U+AC00-D7A3` 을 넣지 마라.** 서브셋이 스스로
  무력화돼 6MB 가 그대로 실린다.
- **SRT 사본에는 UTF-8 BOM.** 없으면 cp949 오탐이 「그럴듯하게 깨진 한글」을 만든다.
- **`codex exec` 의 `-i` 는 가변 인자다.** 뒤에 온 프롬프트까지 이미지로 삼킨다.
  → 프롬프트는 stdin 으로 넘긴다.
- **node 에 `CREATE_NO_WINDOW` 를 주지 마라.** Chrome 자식마다 새 콘솔이 생긴다.
