# 쇼츠공방 II

**단행본 한 장(章)을 넣으면, 화면이 실제로 움직이는 세로 쇼츠가 나옵니다.**

```
1장.pdf   →   20~30초 · 1080×1920 · mp4
1장.md    →   (PDF · DOCX · MD · TXT · HTML 다 됩니다)
```

**말이 그것을 말하는 순간에 자막이 뜨고, 그 순간에 그림이 갈립니다.** 자막 조각의
시각을 글자 수로 어림하지 않고 **음성이 낱말을 언제 발음했는지 실측**해서
붙입니다(edge-tts 의 `WordBoundary`). 조각 경계가 곧 컷이라, 그림도 같은 순간에
튑니다 — 따로 두면 둘 다 죽습니다.

가운데 16:9 그림은 **사람이 넣습니다.** [FlowGenie](https://github.com/leedonwoo2827-ship-it/flowgenie)
용 JSON 을 내보내면 그 이름 그대로 PNG 가 내려오고, 「가져오기」 한 번으로 붙습니다.
한 조각에 PNG 여러 장을 넣으면 **GIF 처럼 넘어갑니다.**

> **API 키가 필요 없습니다. 그리고 로그인이 하나입니다** —
> 원고·대본·장면 지시·올릴 글이 전부 **Claude Code** 구독으로 돕니다.
> (ChatGPT/Codex 는 **두루마리 배치**를 쓸 때만 필요합니다 — 아래 「화면」 참고.)

## 어떻게 도나

```
  ┌ 대본 만들기 ────────────────────────────────┐
  │  재료      PDF 에서 쪽번호·머리글을 걷어낸다    │
  │  원고    $ 소제목을 복원하고 수치를 표로 세운다  │
  │  구조      표에서 사실 목록을 뽑는다 (무료)      │
  │  대본    $ 사실 하나에 씬 하나 · 후크 · 자막    │
  │  발음      1840년 → 천팔백사십 년              │
  │  음성      실측 길이 + **낱말 시각**을 받는다     │
  │  자막      조각을 **낱말 발화 시각에** 붙인다     │
  │  장면지시 $ 조각마다 그림 지시 하나              │
  └───────────────────────────────────────────┘
  ┌ 장면 받기 ──────────────────────────────────┐
  │  ① 내보내기  FlowGenie JSON (크레딧 0)         │
  │  ② (사람)    16:9 로 돌려 PNG 를 받는다         │
  │  ③ 가져오기  04_장면/ 으로 올린다              │
  └───────────────────────────────────────────┘
  ┌ 전체 빌드 ──────────────────────────────────┐
  │  미리보기   굽기 전에 재생해 보고 승인          │
  │  빌드      헤드리스 Chrome 이 프레임을 캡처     │
  └───────────────────────────────────────────┘
       결과   $ 유튜브 제목·설명·태그·고정댓글
```

`$` 네 곳만 크레딧을 씁니다 — **전부 Claude 입니다.** 「장면 받기」는 0입니다.
**구조 단계도 파서라 크레딧이 0입니다** —
몇 번이든 다시 돌려도 됩니다. **묶음 단추는 편의고, 단계는 하나씩 눌러도 됩니다** —
대본은 읽고 고쳐야 하고 장면은 보고 다시 받아야 하니까요.

### 한 편에 드는 것

| | |
|---|---|
| Claude (원고·대본·장면지시·올릴글) | **약 $1.2** |
| FlowGenie (그림 6~10장) | 크레딧 0 · 사람이 한 번 돌린다 |
| 렌더 | 약 50~80초 · 크레딧 0 |
| 결과 | 20~30초 · 1080×1920 · 30fps · **컷 6~10개** |

자막만 고쳐 다시 구우면 렌더만 돌면 됩니다. 조각 수가 바뀌면 「내보내기」를
다시 눌러 그림을 그만큼만 더 받으면 됩니다 — 크레딧이 안 듭니다.

> 두루마리 배치를 쓰면 여기에 **Astra 3~4 메시지 · 약 10분**이 더 붙습니다.

## 화면

배치가 **두 벌** 있습니다. `config.json` 의 `compose.layout` 으로 고릅니다.

### 「카드」 — 기본

```
┌──────────────────┐
│ AI 개발 ▬▬▬▬▬▭▭▭ │  ← y63  시리즈 라벨 · y105 진행 레일(통짜)
│                  │
│     작 곡         │  ← y288 큰 꼭지 제목 (card_title)
│  ⟨유지 · 지난달⟩   │  ← y435 배지 (card_badge)
│       ◍          │  ← y582 로고 (04_장면/_아이콘/NNN.png)
│  Suno 5.5 / …    │  ← y705 모델명 줄 (card_sub)
│ ┌──────────────┐ │
│ │  16:9 그림    │ │  ← y816  972×547. **여기가 갈리는 것이 컷**
│ └──────────────┘ │     한 조각에 PNG 여럿 → GIF 처럼 넘어간다
│ 작곡. 품질은 아직  │  ← y1392 자막이 **단락으로 쌓인다**
│ Suno v5.5예요.    │     조각이 뜨면 앞 줄은 그대로 남는다
└──────────────────┘
```

좌표는 레퍼런스 영상을 프레임으로 뽑아 **행·열 프로파일로 재서** 넣은 값입니다.
첫 씬(`role=hook`)은 **표지 배치**로 굽습니다 — 고정 후크 두 줄이 크게 뜨고
그림이 화면 가운데로 내려갑니다.

**자막이 쌓이는 것이 이 배치의 핵심입니다.** 그래서 조각 시각이 어긋나면 그 틀린
화면이 씬 끝까지 남습니다 — 낱말 발화 시각에 붙이는 이유가 이것입니다.

### 「두루마리」 — 예전 배치 (지우지 않았습니다)

```
┌──────────────────┐
│ 사람이 모이지 않아도 │  ← 위 띠. **영상 내내 고정.**
│ 다니는 학교, 150년 │     둘째 줄의 「150년」만 주황
│                ① │     + 진행 레일 · 항목 번호만 바뀐다
├──────────────────┤
│   움직이는 장면    │  ← 아스트라가 쓴 SVG. 여기가 움직인다
│   (두루마리 한 칸) │     카메라가 칸을 뛰면 그것이 컷이다
├──────────────────┤
│ 한때 미국 최대     │  ← 아래 띠. 조각 하나가 떴다 **꺼진다**
└──────────────────┘
```

`compose.layout` 을 `두루마리` 로 되돌리면 예전 화면이 그대로 나옵니다.
그때는 ChatGPT(Codex) 로그인이 필요합니다.

**장면에는 글자가 없습니다.** 글자는 전부 화면 위에 얹는 층이라, 오타 수정도
모션도 다국어도 공짜입니다. 그림에 글자를 구우면 고칠 수도 움직일 수도 없습니다.

**후크는 씬마다 갈리지 않습니다.** 갈리면 보다 들어온 사람이 무슨 영상인지
모릅니다. 카드 배치에서는 표지가 후크를 지고, 그 뒤로는 좌상단 라벨이 이어
받습니다. 두루마리에서는 영상 내내 상단에 박혀 있고 항목 번호(①~⑧)만 바뀝니다.

```
              source.md    추출본 (고칠 수 있다)

              구조.json    절·블록·표·골격·**사실 목록** ★
  01_대본/    script.json ★ · 발음교정표.txt
  02_음성/    001.wav …
  03_자막/    <slug>.srt · cue-sheet.csv
  04_장면/    장면지시.json
              001-1.png  001-2.png …     ← 조각마다 한 장 (= 컷)
              001-2-01.png … -05.png     ← 한 조각을 GIF 처럼 (플립북)
              _아이콘/002.png             ← 꼭지 로고 (선택)
              _반입/flowgenie.json        ← 내보낸 것 · 받은 그림을 여기 넣는다
              001.svg …                  ← 두루마리 배치 (아스트라)
  05_컴포지션/ index.html · assets/
  06_완성/    v01_.../<slug>.mp4 · 유튜브.txt · 대본.txt
```

**`00_기획/구조.json` 의 `facts` 가 대본의 유일한 근거입니다.** 여기에 사실이
없으면 대본이 근거 없이 쓰고, 그러면 그림이 장소만 그리고 주장이 사라집니다.
「재료 → 구조」 탭에서 눈으로 확인하세요 — 크레딧이 안 드니 몇 번이든 다시 뽑으세요.

**`04_장면/` 은 접점입니다.** 앞 세 자리가 씬 번호이고, 그 뒤는 이렇게 읽습니다:

```
001.png          씬1 · 조각1          (예전 이름 — 그대로 돕니다)
001-2.png        씬1 · 조각2          ← 조각 경계에서 갈린다 = 컷
001-2-03.png     씬1 · 조각2 · 프레임3  ← 조각 안에서 넘긴다 = 플립북
001-교회.svg     씬1 · 조각1          ← 숫자가 아닌 꼬리는 설명이라 무시
```

같은 자리에 확장자가 여럿이면 `.mp4 > .svg > .png > .jpg > .webp` 순으로
이깁니다. 한 조각에 `001-2.png` 와 `001-2-01.png` 이 같이 있으면 **번호를 적은
쪽이 이깁니다** — 안 그러면 정렬 순서가 정하고, 그러면 아무도 모르게 한
프레임이 가려집니다.

★ **진짜 `.gif` 는 받지 않습니다.** 렌더가 GSAP 시계를 되감아 가며 찍는데 GIF 은
되감을 API 가 없어 **오류도 경고도 없이 첫 프레임에 멈춥니다.** 「가져오기」가
ffmpeg 로 PNG 시퀀스로 풀어 넣습니다 — 그러면 플립북 길로 들어와 제대로 넘어갑니다.

## 왜 이렇게 만들었나

### 장면은 한 방향으로 한 번만 움직인다

처음엔 `repeatCount="indefinite"` 로 무한 반복시켰습니다. 그랬더니 아스트라가
이음새가 안 보이도록 **처음 값으로 되돌아오는** 동작을 썼고, 화면이 8초 내내
안절부절못했습니다.

지금은 한 방향으로 한 번 가서 **그 자리에 멈춥니다.** 되돌아오는 `values` 는
검사기가 잡아 다시 시키고, 되풀이를 뜻하는 말(「주기」「흔들」「되돌아」)이 지시에
섞이면 그 단계에서 한 번 더 물어봅니다. 마지막 씬은 동작 창을 60% 만 줘서,
**정지한 화면 위로 마무리 말이 얹힙니다.**

### 역동성은 동작 수가 아니라 컷 수다

잘 도는 세로 쇼츠를 여러 편 재어 보니, 자막이 6~10자 조각으로 흐르고
**조각마다 화면이 바뀌었습니다** — 컷당 1.5~2초, 30초에 15~20컷.

우리 v13 은 씬 4개에 씬당 자막 2줄이라 **컷이 4개**였습니다. 한 화면 안에서
정교하게 움직여도 그것으로는 안 됩니다. 그런데 씬을 늘려 컷을 늘리면 씬 하나가
아스트라 2분 30초 + 한도라 비용이 곧 막습니다.

그래서 **두루마리**입니다. 씬 하나를 화면 몇 개분 높이로 그리게 하고 카메라가
칸에서 칸으로 끊어 뜁니다. 값 하나에 컷 여럿입니다.

카메라 시각은 **자막 큐 경계**이고, 그 큐는 음성 실측에서 나옵니다.
그래서 자막 조각과 화면이 같은 순간에 튑니다 — 따로 두면 둘 다 죽습니다.

### 씬 수를 사람이 정하지 않는다

예전에는 화면에 「컷」 숫자칸이 있었고 그 값이 프롬프트에 「씬 수는 4개다」로
박혔습니다. 그러면 원문이 18쪽이든 2쪽이든 대본이 4로 맞춰 나옵니다 —
열네 판을 만들어도 갈피가 안 잡힌 원인 중 하나가 이것이었습니다.

지금은 사람이 정하는 것이 **형식과 길이 범위뿐**입니다. 나머지는 파생값입니다:

```
형식 · 20~30초  →  글자 예산  →  항목(사실이 부르는 만큼)  →  실측 초
                →  자막 조각  →  컷  →  칸  →  두루마리(= 아스트라 메시지)
```

### 줄글 덩어리를 바로 대본에 넘기지 않는다

PDF 추출이 소제목을 본문에 붙여 버립니다 — 실측으로 18쪽 한 장이 헤딩 **한 개**
짜리 덩어리로 나왔고, 대본이 **첫 단락만 잡고 나머지 17쪽을 버렸습니다.**

그래서 가운데에 두 단계를 넣었습니다. **원고**가 소제목을 복원하고 수치·연표·비교를
`<table>` 로 세우고, **구조**가 그 표를 읽어 사실 목록을 만듭니다. 구조는 파서라
크레딧이 0입니다 — 모델에게 배열을 맞춰 달라고 하면 어긋나고, 어긋나면 조용히
틀립니다.

### 그림이 바뀌어야 하면 칸을 늘린다

한 칸 안에서 장면이 다른 장면으로 바뀌면 그건 컷이고, 컷은 칸이 하는 일입니다.

### 인증 두 개를 코드로 잇지 않는다

Claude 와 ChatGPT 를 한 프로세스에 섞지 않습니다. 장면 단계는 **별도
서브프로세스**에서 돌고, 각자 자기 자격증명만 읽습니다. 부르기 전에 상대편
API 키 환경변수를 빈 값으로 덮습니다 — 오래된 `export` 가 구독 대신 키로 나가면
모르는 사이에 과금됩니다.

### 다시 밟지 말 것 — 실측으로 배운 것

레포 안에서 자동으로 검사합니다: `python tools/lint_repo.py`

- **여러 SVG 를 한 문서에 심으면 `id` 가 충돌한다.** 아스트라가 쓴 네 장면이 전부
  `id="scene"` 을 썼고, `url(#scene)` 이 모두 첫 번째로 붙어 **뒤 씬이 통째로
  비었다.** 오류도 경고도 없었다. → 씬마다 접두어를 붙인다.
- **SMIL 은 문서 시계다.** 씬 2 가 7.9초에 떠도 그 애니메이션은 0초부터 돌고
  있다. → 씬 등장 시각에 위상을 맞춘다.
- **GSAP `drawSVG` 는 유료 플러그인이다.** 무료 빌드에 없고, 없으면 예외도 없이
  아무 일도 안 한다. → dash 로 긋는다.
- **폰트 서브셋 `--unicodes` 에 `U+AC00-D7A3` 을 넣지 마라.** 서브셋이 스스로
  무력화돼 6MB 가 그대로 실린다.
- **SRT 사본에는 UTF-8 BOM.** 없으면 cp949 오탐이 「그럴듯하게 깨진 한글」을 만든다.
- **`codex exec` 의 `-i` 는 가변 인자다.** 뒤에 온 프롬프트까지 이미지로 삼킨다.
  → 프롬프트는 stdin 으로 넘긴다.
- **node 에 `CREATE_NO_WINDOW` 를 주지 마라.** Chrome 자식마다 새 콘솔이 생긴다.
- **표 셀을 구분자 없이 이어 붙이지 마라.** 41_26 이 그렇게 해서
  「성장의 제약토지의 수확 체감환경의 용량 한계」가 됐다. 대본이 숫자를 골라
  써야 하는데 그러면 못 가른다. → `tables[].rows` 로 셀을 살린다.
- **단위가 열머리에 있는 표를 놓치지 마라.** 「성장률(%/연)」 열의 `7.6` 은
  셀만 보면 맨 숫자다. 그리고 괄호 안을 먼저 봐야 한다 — 「평균수명(년)」에서
  '평균수명' 의 `명` 을 먼저 집으면 71년이 71명이 된다.
- **두루마리 viewBox 를 문서 최상위 canvas 로 재지 마라.** 씬마다 높이가 다르다.
  씬별 `canvas_h` 로 재야 한다 — 안 그러면 칸이 여러 개인 씬이 전부 검사에 걸린다.
- **아스트라에게 넘길 씬 필드를 손으로 골라 담지 마라.** `s6_art` 가 목록으로
  골라 담고 있었는데, 두루마리를 넣을 때 `canvas_h`·`cells` 가 조용히 빠졌다.
  결과: 아스트라가 한 화면만 그렸고 검사기는 칸 수를 1 로 계산해 그걸 통과시켰다 —
  **둘이 같은 원인으로 동시에 눈이 멀었다.** 통째로 넘기고 `_` 로 시작하는 것만 뺀다.
- **칸을 잇는 선을 그리게 두지 마라.** 아스트라가 세 칸을 잇겠다고 위에서 아래로
  얇은 선을 하나 그었다. 카메라는 한 번에 한 칸만 잡으므로 그것은 이음으로 안
  읽히고 화면을 관통하는 획이 된다. **흐름은 음성과 드러남이 만든다.**
  `tools/check_scroll.mjs` 가 `getBBox()` 로 좌표를 재서 되돌려보낸다 —
  `d` 를 정규식으로 재려 하면 상대 명령(c·l·v)에 곧 틀린다.
- **그 검사기에서 캔버스 밖을 먼저 잘라라.** 화면 위로 살짝 삐져나간 장식이
  `y=-121` 로 잡혀 「칸 0 과 칸 1 을 넘는다」는 오탐이 됐고, 멀쩡한 두루마리가
  되돌려보내졌다. SVG 는 viewBox 밖을 어차피 잘라 그린다. **검사기를 새로 만들면
  통과해야 하는 것 한 장과 걸려야 하는 것 한 장으로 먼저 시험하라** —
  걸려야 하는 것만 시험하면 오탐을 못 본다.
- **`<text>` 만 막으면 글자가 새어 든다.** 속기 기호·필기체를 `path` 로 그려도
  사람 눈에는 글자로 읽힌다. 프롬프트에서 「낱말 모양을 만들지 마라」까지 적어야 한다.
- **그림을 처음부터 다 켜 두면 4초가 정적이다.** 실측: 아스트라가 전부 보이게
  두고 뒤늦게 2.3~4.0초에 잔가지 11개만 터뜨렸다. 자막 조각 시각을 넘겨 주고
  **말이 그것을 말할 때 그것이 들어오게** 해야 한다. 드러남에 `transform` 을
  같이 걸지 않으면 슬라이드쇼가 된다.
- **시간표를 두 개 주지 마라.** 자막 조각은 0.0/1.66/3.49 인데 박자는 0.3/1.5/2.7
  이면 아스트라가 어느 쪽에 맞출지 모른다. 코드가 박자를 조각에 붙인다 —
  **글은 모델의 것, 시각은 코드의 것.**
- **단계마다 예산 뚜껑이 다르다.** 「원고」는 16,212자를 읽고 HTML 을 통째로 써
  내므로 공통 상한 $1.5 를 넘겨 죽었다(`Reached maximum budget`). 모델도 opus 에서
  sonnet 으로 내렸다 — 재구성은 창작이 아니라 자리 옮기기다($1.5 사망 → $0.45 성공).
- **인용 대조 전에 문장부호를 맞춰라.** 모델이 굽은 따옴표를 곧은 것으로 정규화해
  보내서 근거 55개 중 8개가 「원문에 없다」는 오탐으로 떴다.
- **겹친 단위를 한 조각으로 읽지 마라.** 「2만5천 명」을 5,000명으로 읽었다 —
  「2만」을 놓치고 「5천」만 집었다. 조각마다 곱해 더해야 한다.
- **칸 높이는 화면 높이가 아니라 그림칸 높이다.** 아스트라에게 「칸 하나가
  1080×1920, 위 300 / 아래 320 비워라」고 알려 줬는데 실제 그림칸은 1080×**1620**
  이다. `preserveAspectRatio="slice"` 가 두루마리 위아래를 450px 씩 잘라내서
      칸1  viewBox  450~2070   그릴 자리 300~450 이 잘려 나갔다
      칸2  viewBox 2070~3690   온전하다
      칸3  viewBox 3690~5310   그릴 자리 5310~5440 이 잘려 나갔다
  **첫 칸은 위가, 마지막 칸은 아래가 잘리고** 그림이 위로 밀려 띠에 걸쳤다.
  지금은 칸 높이를 `art_h`(=width×3/2=1620)로 잡고 비울 자리를 위 150 / 아래 170
  으로 다시 재서 넣었다 — 두루마리 높이와 카메라 판 높이가 같아져 잘림이 없다.
  `s5_artspec.ART_RATIO` 는 **`s7_compose.ART_RATIO` 와 같은 값이어야 한다.**
- **세로 정렬을 칸마다 못 박아라.** 잘림을 고쳐도 「위로 쏠렸다 아래로 쏠렸다」가
  남는다. `fill` 을 「낱개·꽉·여백」으로만 주면 아스트라가 세로 위치를 제 맘대로
  잡는다 — 실측으로 밭·교회는 칸 아래로, 종이는 칸 위로 붙었다. 컷이 갈릴 때
  **컷이 갈리는 게 아니라 그림이 흔들리는 것으로 보인다.**
  칸마다 「세로 가운데 y=…」 좌표를 주고 남는 자리를 위아래로 고르게 비우게 한다.
- **낭독 속도는 문장 길이에 딸려 있다.** 같은 목소리·같은 배속인데 짧은 문장
  11개(평균 20자)는 6.5자/초, 긴 문장 7개(평균 45자)는 8.1자/초가 나왔다.
  문장마다 시작·끝의 여유가 붙어서 짧게 끊으면 그 여유가 문장 수만큼 곱해진다.
  **「끊겨 들린다」와 「말이 느리다」는 같은 원인이고, 배속으로 고칠 문제가 아니다.**
- **자막 조각 한도는 「강제 분할」 한도로만 쓴다.** 문장 끝에서 먼저 자르고, 그
  한도를 넘는 문장만 더 쪼갠다. 한도를 40 으로 두면 52자 문장이 둘로 갈려
  호흡이 다시 끊긴다 — 60 이면 한 문장이 온전히 한 자막이 된다.
- **레일을 접으면 다시 펼 단추가 남아 있어야 한다.** 접힌 폭 62px 에 브랜드바가
  89px 을 먹어 토글이 `overflow:hidden` 에 잘려 클릭이 안 됐다. 그리고 글 쓰는
  칸에서 Ctrl+B 를 가로채지 마라 — 굵게 하려고 누른 것이 레일을 접었다.
- **켄번스와 카메라를 같이 걸지 마라.** 두 움직임이 싸워서 둘 다 안 읽힌다.
  켄번스는 **칸이 하나인 정지 그림에만** 남긴다.
- **폰트 서브셋에 고정 후크와 항목 번호(①~⑧)를 넣어라.** 빠뜨리면 그 글자만
  맑은고딕으로 떨어져 화면에서 홀로 다른 폰트가 된다.
- **`mark` 가 후크 둘째 줄에 없으면 강조를 씌울 수 없다.** 코드가 그때는 줄 전체를
  강조로 떨어뜨린다 — 없는 낱말을 찾다 실패하는 편보다 낫다.
- **edge-tts 에 `boundary="WordBoundary"` 를 주지 않으면 낱말 시각이 안 온다.**
  기본값이 `SentenceBoundary` 라서 문장 하나에 이벤트가 **한 개**만 온다. 실측:
  같은 문장에 기본값 1개 vs 명시 9개(= 어절 9개). 그리고 `Communicate.save()` 는
  그 이벤트를 **버린다** — `stream()` 으로 받아야 한다.
- **낱말 시각에 배속 보정을 하지 마라.** 실측(ko-KR-SunHiNeural, 어절 9개):
  `+0%` wav 5.448초·마지막 낱말 끝 4.575초 / `+20%` wav 4.560초·3.821초.
  비가 1.195 : 1.197 로 **같이 줄었다.** offset 이 이미 배속 시간선이라
  1.2 로 나누면 두 번 보정된다.
- **자막은 `srt_text` 에서 쪼개고 음성은 `narration_text` 를 읽는다.** 「1840년」이
  「천팔백사십 년」으로 읽히므로 **낱말끼리는 못 맞춘다.** 문장은 그대로 남으니
  문장 경계만 마크에 붙이고 문장 안에서만 글자 수로 나눈다. 그리고 마크가
  **어느 글에서 나왔는지 지문으로 대조하라** — 사람이 발음 대본을 손으로 고치면
  어절 수가 우연히 맞아 엉뚱한 낱말에 자막이 붙는다.
- **낱말 시각이 없으면 소리가 맞아도 다시 구워라.** 예전에 구운 씬에는 `marks` 가
  없고 스탬프만 보면 영원히 건너뛴다 — 정렬이 기존 작업물에는 **끝까지 안 켜진다.**
  단, 마크를 안 주는 엔진(voicewright)에서 이 조건을 걸면 매번 전부 다시 굽는다.
- **진짜 `.gif` 를 그림칸에 넣지 마라.** 렌더는 GSAP 시계를 되감아 가며 찍는데
  GIF 은 벽시계로 돌고 **되감을 API 가 없다** — SMIL 은 `setCurrentTime()` 이라는
  손잡이가 있어 고쳤지만 GIF 엔 없다. 오류도 경고도 없이 첫 프레임에 멈춘다.
  반입할 때 ffmpeg 로 **PNG 시퀀스로 풀어** 플립북 길로 들여보낸다.
- **플립북 프레임을 앞에서 자르지 마라.** 상한을 넘으면 **균등 간격으로 골라라** —
  움직임의 끝이 그 움직임의 뜻인 경우가 많다. 그리고 프레임이 조각 길이보다
  많으면 간격을 좁혀 다 넣는다(자르지 않는다).
- **`NNN-M.png` 와 `NNN-M-01.png` 이 같이 있으면 정렬 순서가 이긴다.** 둘 다 「조각
  M 의 첫 프레임」을 노리는데 규칙이 없으면 **아무도 모르게 한 프레임이 가려진다.**
  번호를 적은 쪽이 이기게 못 박아라.
- **조각보다 뒤에 붙은 그림은 화면에 안 나온다.** 조각이 2개인데 `003-3.png` 을
  넣으면 갈 자리가 없다 — 자막을 줄여 조각이 줄었을 때 실제로 생긴다.
  조용히 버리면 사람은 「넣었는데 안 보인다」만 겪는다. **로그와 화면에 적어라.**
- **씬을 지울 때 꼬리 붙은 이름까지 잡아라.** `04_장면/{NNN}.*` 만 글롭하면
  `001-2.png`·`001-2-03.png` 이 **남아서 새 씬에 옛 그림이 붙는다.** 번호를 밀 때도
  앞 세 자리만 갈고 꼬리는 그대로 둬야 한다 — 확장자만 붙여 다시 만들면 한 씬의
  그림이 전부 한 장으로 뭉친다. 로고 폴더(`_아이콘/`)도 같이 봐야 한다.
- **쌓이는 자막은 `tl.from` 만으로는 안 된다.** 트윈이 시작되기 전에는 요소가
  제 상태(= 보임)라서 씬이 뜨는 순간 그 씬의 조각이 **전부 한꺼번에 보인다.**
  떴다 꺼지던 배치는 조각마다 `.clip` 이 따로여서 게이팅이 가려 줬는데, 한 단락
  안의 `<span>` 은 개별로 안 걸린다. 0초에 먼저 꺼 두고 `fromTo` 로 양 끝을 박아라.
- **꼭지 머리는 카드 **위쪽**에 앉혀라.** 아래(카드 위 57px)에 앉히니 배지·캡션·
  로고가 없는 꼭지에서 제목이 y665 로 내려앉아 **y130~660 이 텅 비었다**(실측
  프레임). 카드는 절대 위치라 머리가 위에 있어도 밀리지 않는다.
- **CSS 크기 규칙을 파일 끝에 덧붙이지 마라.** `.srow` 격자와 `.slide` 크기,
  `.sl-hook`·`.sl-cap` 글자 크기가 위쪽과 파일 끝에 **두 벌** 있었다. 그러면
  위쪽을 고쳐도 **아무 일도 안 일어난다**(뒤가 이긴다). 옮겨 쓰고, 붙이지 마라.
- **단추 결과를 DOM 에만 쓰지 마라.** 「내보내기」가 끝나고 `loadProject()` 가
  화면을 다시 그리면서 로그가 통째로 사라졌다 — 눌렀는데 아무 일도 안 일어난
  것처럼 보였다. 상태에 담고 다시 그릴 때 이어 보여 준다.
- **「없어도 되는 것」에 빨간불을 켜지 마라.** 카드 배치는 Codex 가 필요 없는데
  칩이 빨갛게 떠 있으면 사람이 로그인하려고 시간을 버린다. 거짓 초록도 안 된다
  (그 반대로 물린 적이 있다). **회색 「선택」**으로 둔다.
- **크레딧을 안 쓰는데 `$` 를 달지 마라.** 단계 표에 `costs=True` 가 박혀 있어서,
  카드 배치에서도 화면이 「$」와 「가장 비싼 자리입니다」를 그대로 말했다.
  표는 하나로 두고 **화면이 받는 모양만** 배치에 따라 갈아 준다.
