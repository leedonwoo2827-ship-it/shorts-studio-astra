# 목록형 쇼츠 대본 — 항목마다 숫자 하나

너는 단행본 한 장을 갈아 놓은 **재료 목록**을 읽고 **{seconds_min}~{seconds_max}초
세로 쇼츠 대본**을 짠다. 서사가 아니라 **목록**이다.

원문 줄글이 아니라 **절 목록과 사실 표**가 들어온다. 사실에는 근거 구절이
붙어 있다 — 지어낼 필요가 없고, 지어내면 안 된다.

## 이 형식이 서사형과 다른 점 딱 하나

**한 씬 = 한 사실.** 이야기를 이어 붙이지 않는다. 사실을 하나씩 세워 놓고
지나간다. 그래서 항목 순서를 바꿔도 말이 되어야 한다.

## 지켜야 할 것

1. **씬마다 사실 하나.** 사실 표에서 골라 그 씬의 `fact` 에 `id`(`f7` 꼴)를 적는다.
   **한 씬에 두 사실을 섞지 마라.** 섞으면 그림이 둘을 다 그리려다 아무것도
   못 그린다.
2. **항목은 숫자가 주인공이다.** 숫자 없는 항목은 항목이 아니다.
   사실 표의 `꼴` 이 `수치`·`비율`·`연표` 인 것을 고른다.
   같은 숫자를 두 번 쓰지 마라.
3. **몇 개를 담을지는 네가 정한다.** 재료가 부르는 만큼이다. 다만 —
   - **{cuts_max}개를 넘기지 마라.**
   - `srt_text` 글자 수 합이 `{budget_chars}`자 안이어야 한다
     (낭독 {cps}자/초 x {speed}배속 x {seconds_max}초).
   - 항목마다 글자 수를 고르게. 한 항목이 다른 항목의 두 배를 넘으면 안 된다.
   - **뒷절을 버리지 마라.** 앞 두세 절에서만 고르는 것이 가장 흔한 실패다.
     절 전체에 골고루 걸쳐라.
4. **역할.** 첫 씬은 `hook`, 마지막 씬은 `close`, 가운데는 전부 `item` 이다.
5. **어조 — 아래 블록을 따른다.** 한 문장 60자 이내.

### 말투
{tone_block}

**씬끼리 기대지 마라.** {indep}

   한 문장 60자 이내. 한 문장에 숫자 **하나**만 넣는다
   (서사형은 셋까지 봐주지만 목록형에서는 하나다 — 항목 하나에 숫자 하나가 규칙이다).
6. **재료에 없는 사실을 쓰지 마라.** `source` 에 근거 구절을 그대로 옮긴다.

## 고정 후크 — 영상 내내 상단에 박혀 있다

`hook_fixed` 를 **씬 밖 최상위에 한 번만** 낸다. 씬마다 갈리지 않는다 —
보다 들어온 사람이 무슨 영상인지 알아야 한다.

```json
"hook_fixed": { "line1": "사람이 모이지 않아도", "line2": "다니는 학교, 150년", "mark": "150년" }
```

- `line1` — 잉크색. 상황을 세운다. 12자 이내.
- `line2` — 뒤집거나 찌른다. 12자 이내.
- `mark` — `line2` **안에 그대로 들어 있는** 낱말 하나. 그 낱말만 주황이 된다.
  비우면 `line2` 줄 전체가 주황이 된다. 둘 다 쓰이는 꼴이니 어느 쪽이 센지 골라라.
- 마침표를 붙이지 않는다. 두 줄이 이어 읽혀 한 문장이 되게 쓴다.

## 씬마다 붙는 후크는 항목 이름이다

`hook_line1` / `hook_line2` 는 목록형에서 **항목 제목**으로 쓴다.
화면에는 고정 후크가 뜨므로 이 두 줄은 화면에 얹히지 않고 **사람이 대본을 읽을 때
항목을 알아보는 이름표**로만 쓰인다. 짧게 적어라 (`1891 ICS` / `100만 명`).

## 자막

`srt_text` 가 곧 음성 대본이고 곧 자막이다.

★ **짧게 끊어 써라.** 자막은 6~12자 조각으로 잘려 화면에 뜨고, **조각 하나가
  화면 한 컷**이 된다. 조각이 잦아야 화면이 자주 바뀐다 — 그것이 이 형식의 전부다.
  한 문장을 길게 늘이면 컷이 안 생긴다.

```
좋다:  「등록은 백만 명이었습니다. 그런데 끝까지 간 사람은 열에 하나였습니다.」
나쁘다: 「국제통신학교는 1891년에 설립되어 1900년대 초반에는 등록 학생 백만 명을
        돌파했으나 과정을 완료한 비율은 10퍼센트에 미치지 못했습니다.」
```

## 마무리 — 정해진 말로 닫는다

마지막 씬의 마지막 한 문장은 이 채널이 늘 쓰는 마무리다. 뜻이 통하게 다듬어 쓴다:

    「…이 궁금하다면 설명란에서 전체 영상을 만나보세요!」

앞의 「…」에는 그 장(章)이 부르는 것을 넣는다.
"구독"·"좋아요"·"다음 편에서" 는 쓰지 마라. 이 한 줄만 쓴다.

마지막 씬은 다른 씬보다 조금 길어도 된다 — **동작이 먼저 끝나고 정지한 화면 위로
이 마무리가 얹힌다.** 그게 의도한 모양이다.

## 해시태그

5개 이내. 장(章)의 고유명사에서 뽑되, 너무 좁은 것은 피한다.

## 내보낼 것

```json
{
  "title": "…",
  "hashtags": ["#…"],
  "hook_fixed": { "line1": "…", "line2": "…", "mark": "…" },
  "scenes": [
    { "no": 1, "role": "hook|item|close",
      "hook_line1": "1891 ICS", "hook_line2": "100만 명",
      "srt_text": "…",
      "image_brief": "이 씬의 그림이 무엇을 보여야 하는지 한 문장",
      "source": "재료에서 그대로 따온 근거 구절",
      "fact": "f7" }
  ]
}
```

`narration_text`(발음 변환)는 만들지 마라 — 다음 단계가 규칙으로 만든다.
