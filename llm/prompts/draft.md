# 원고 — 줄글 한 덩어리를 다시 짠 HTML 로

PDF 에서 뽑은 줄글이 들어온다. 이것을 **소제목이 살아 있고 수치가 표로 뽑힌
HTML 원고**로 다시 짠다. 다음 단계는 사람이 아니라 **파서**다 — 이 HTML 의
태그를 읽어 대본이 쓸 재료 목록을 만든다.

## 왜 이 단계가 있나 — 실측으로 이랬다

PDF 추출이 소제목을 본문에 붙여 버린다. 실제로 이렇게 들어왔다.

```
…교실의 문피트먼의 실험은 고립된 사건이 아니었다
빛과 그림자— 통신교육의 약속과 배신통신교육은 기회의 문을 열었지만…
전파가 만든 공동의 청취우편이 교육을 공간으로부터 해방시켰다면…
```

그래서 18쪽 원문에 헤딩이 **한 개**뿐이었고, 대본 단계는 이 덩어리에서
**첫 단락만 잡고 나머지 17쪽을 버렸다.** 소제목을 떼어 복원하는 것이
이 단계의 첫째 일이다.

둘째 일은 **숫자를 건져 내는 것**이다. 같은 원문에 이런 것들이 묻혀 있었다 —
1페니 균일요금, 우편량 1년에 2배, 등록 7만에서 100만, 수료율 10퍼센트 미만,
한 세기 뒤 5퍼센트 미만. 줄글에 섞여 있으면 아무도 못 쓴다. **표로 세워 놓으면
대본이 골라 쓴다.**

## 무엇을 내보내나

`html` 필드 하나에 HTML 조각을 담는다. `<html>`·`<head>`·`<body>`·`<style>` 은
쓰지 마라 — 조각만이다.

### `<h2>` = 원문의 절

원문에서 소제목을 찾아 복원한다. 없으면 그 절이 말하는 것을 한 줄로 지어 붙인다.
**절 순서를 원문 그대로 지킨다.** 앞뒤를 바꾸지 마라.

### 절마다 `<p>` 한 줄 + `<ul><li>` 두 줄

`<p>` 는 그 절의 요지 한 문장. `<li>` 는 그 요지를 받치는 사실 두세 개.
한 줄에 50자 안쪽으로 짧게 끊어라 — 화면에 얹힐 글이 아니라 **다음 단계가 읽는
목록**이다.

### 숫자·연표·비교는 `<table>` 로

★ **이것이 이 단계의 요점이다.** 원문에 숫자가 있으면 줄글로 두지 말고 표로 세운다.

```html
<table>
  <thead><tr><th></th><th>1891</th><th>1895</th><th>1900년대 초</th></tr></thead>
  <tbody>
    <tr><td>등록 학생</td><td>설립</td><td>7만 명</td><td>100만 명</td></tr>
  </tbody>
</table>
```

- **셀을 반드시 나눠라.** 한 칸에 「7만100만」처럼 붙여 넣으면 파서가 못 가른다.
- 세 꼴 중 하나로 잡는다 — **연표**(가로축이 연도) · **비교**(두 열이 맞선다) ·
  **지표**(행이 항목, 열이 값).
- 단위는 셀 안에 적는다(`7만 명`, `10%`, `1페니`).
- 표에 없는 숫자를 만들지 마라. 원문에 있는 것만이다.

### 추세·대비는 `<svg>` 골격 — 통틀어 **세 개까지**

절마다 넣지 마라. **가장 셀 만한 것 세 개**만 고른다. **최종 화면이 아니다** —
다음 단계의 그림 모델에게 넘길 **도해 초안**이다. 그래서 여기서는 글자를 넣어도
된다(장면 SVG 와 규칙이 다르다).

```html
<svg viewBox="0 0 520 190" xmlns="http://www.w3.org/2000/svg"
     font-family="sans-serif" font-size="12" role="img"
     aria-label="한 줄로 무엇을 보이는 그림인지">
  <line x1="60" y1="30" x2="60" y2="160" stroke="#CBD5E1"></line>
  ...
</svg>
```

- `viewBox` 는 **`0 0 520 190` 고정.** 다른 값을 쓰지 마라.
- 색은 이 다섯만 — 진한 파랑 `#1F4E79` · 중간 파랑 `#2E75B6` ·
  밝은 파랑 `#9DC3E6` · 옅은 하늘 `#DEEBF7` · 가구선 `#CBD5E1`/`#94A3B8`.
- `aria-label` 을 반드시 적어라. 파서가 그 문장으로 골격의 뜻을 읽는다.
- `<script>`·바깥 그림·`<foreignObject>` 는 넣지 마라.

### `data-quote` 는 **숫자가 든 곳에만**

`data-quote="원문에서 그대로 따온 구절"` 을 붙일 곳은 —

- **표의 모든 `<tr>`** (머리 행 포함)
- **숫자·연도·비율이 들어간 `<li>` 와 `<p>`**
- `<svg>` 골격

숫자가 없는 `<p>`·`<li>` 에는 **붙이지 마라.** 근거가 필요한 것은 수치이고,
전부에 붙이면 원고가 두 배로 길어져 예산을 넘긴다(실측으로 그랬다).

```html
<li data-quote="1895년에는 등록 학생이 7만 명을 넘었고, 1900년대 초반에는 100만 명을 돌파했다">
  등록 학생이 7만에서 100만으로 늘었다</li>
```

## 지켜야 할 것

1. **원문에 없는 사실을 쓰지 마라.** 인물·연도·수치·비율은 원문에서만 가져온다.
   해석을 덧붙이지 말고, 원문이 한 말을 자리만 옮겨라.
2. **버리지 마라.** 원문의 절이 일곱 개면 `<h2>` 도 일곱 개다. 앞부분만 촘촘히
   쓰고 뒤로 갈수록 성기게 쓰는 것이 이 단계에서 가장 흔한 실패다.
   **뒷장이 앞장보다 얇으면 다시 써라.**
3. **숫자가 있는 절에는 표가 있어야 한다.** 숫자를 `<p>` 안에 묻어 두지 마라.
4. 태그는 `h2` · `p` · `ul` · `li` · `b` · `table` · `thead` · `tbody` · `tr` ·
   `th` · `td` · `svg` 와 그 안쪽만 쓴다. `div`·`span`·`class`·`style` 은 쓰지 마라.
5. 한 절이 `<p>` 하나에 `<li>` **두 개**면 충분하다. 원문을 옮겨 적는 것이 아니라
   **재료를 세워 놓는 것**이다. 한 줄은 50자 안쪽으로 짧게.
6. **짧게 써라.** 이 원고는 사람이 읽는 글이 아니라 다음 단계가 읽는 목록이다.
   길게 쓰면 예산을 넘겨 통째로 죽는다 — 실측으로 그랬다.

## 내보낼 것

```json
{
  "html": "<h2>…</h2><p data-quote=\"…\">…</p><ul><li data-quote=\"…\">…</li></ul><table>…</table><svg …>…</svg><h2>…</h2>…",
  "warnings": ["원문에서 소제목을 찾지 못해 지어 붙인 절: 3번째"]
}
```

`warnings` 는 사람이 봐야 할 것만 적는다. 없으면 빈 배열이다.
