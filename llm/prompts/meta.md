# 유튜브 쇼츠 올릴 글

만들어진 쇼츠에 붙일 **제목·설명·태그·고정댓글**을 쓴다.

## 지켜야 할 것

1. **제목** — 40자 안. 낚시하지 마라. 영상이 실제로 말하는 것을 말해라.
   숫자나 모순이 있으면 그것을 앞에 둔다. `#쇼츠` 같은 태그를 제목에 넣지 마라.
2. **설명** — 세 덩어리로 쓴다.
   - 첫 두 줄: 영상 내용 요약. 여기까지만 접히지 않고 보인다.
   - 가운데: 원본 글의 출처(책 제목과 장). 아래 「출처」에 준 것을 그대로 쓴다.
   - 끝: 해시태그 줄.
   원본 영상 링크 자리가 있으면 `{원본링크}` 를 그대로 남겨라 — 사람이 채운다.
3. **태그** — 5~12개. 영상에 실제로 나오는 고유명사와 주제어만. 뜬 태그를 넣지 마라.
4. **고정댓글** — 한두 문장. 본문에서 못 다룬 사실 하나를 더 주거나,
   보는 사람에게 물음을 던진다. 구독을 요구하지 마라.
