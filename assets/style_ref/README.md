# 화풍 기준 그림

이 폴더의 PNG 는 **이 채널의 화풍 계약**입니다. 아스트라가 장면 SVG 를 쓸 때
`codex exec -i` 로 이 그림을 함께 봅니다.

출처는 `summary-showcase` 로 만든 롱폼(새뮤얼슨 경제학 26장)의 삽화이고,
`gpt-image` 가 그린 것입니다. 여기서 참고하는 것은 **밀도**입니다 —

- 인물이 실루엣이 아니라 **얼굴·머리·손·옷 주름까지** 있다
- 배경·중경·전경 세 층이 있다 (창밖 풍경 · 인물 · 앞쪽 소품)
- 소품이 여럿이다 (책·지구본·깃펜·책상)
- 그런데도 **플랫 벡터**이고 선 굵기가 균일하다

★ **글자는 참고 대상이 아닙니다.** 이 그림들에는 라벨이 인쇄돼 있지만,
  우리 장면에는 글자를 넣지 않습니다(앱이 띠에 얹습니다). 프롬프트가
  그렇게 못 박습니다.

★ 화풍을 바꾸려면 이 파일을 갈아 끼우세요. `config.json` 의
  `art.style_refs` 가 여기를 가리킵니다.

# 쇼츠풍 — 잘 도는 세로 쇼츠를 여러 편 보고 모은 것

화풍이 그림 한 장의 규칙이라면, 이것은 **30초의 규칙**입니다.

### 1. 역동성은 화면이 몇 번 바뀌느냐로 온다

한 화면 안에서 몇 개가 움직이느냐가 아닙니다. 잘 도는 세로 쇼츠는
**자막 한 조각(6~10자)마다 화면이 바뀝니다** — 컷당 1.5~2초, 30초에 15~20컷.

씬 4개에 씬당 8초면 아무리 정교하게 움직여도 컷은 4개입니다. 그래서 씬 하나를
**긴 지면(두루마리)** 으로 그리고 카메라가 칸에서 칸으로 **끊어 뜁니다.**
뛰는 것이 컷입니다. 장면 값은 하나인데 컷은 여럿입니다.

### 2. 자막 조각과 컷은 같은 시각에 튄다

따로 두면 둘 다 죽습니다. 자막 큐가 음성 실측에서 나오니, 카메라도 큐 경계에서
코드가 만듭니다 — 모델이 시각을 찍지 않습니다.

### 3. 상단 후크는 영상 내내 고정이다

두 줄, 둘째 줄이 강조색. 강조는 **줄 전체**일 수도 **낱말 하나**일 수도 있습니다.
씬마다 바꾸면 보다 들어온 사람이 무슨 영상인지 모릅니다. 바뀌는 것은 항목 번호뿐.

### 4. 자막은 크고 굵고 강조색이다

옅은 본문색·본문 크기로는 숫자가 안 읽힙니다. 숫자를 읽히게 하는 것이 요점입니다.

### 5. 컷마다 화면 채움이 다르다

바탕에 사물 하나 / 세로로 꽉 / 가로로 넓게 두고 위아래 여백.
**전부 꽉 채우면 리듬이 없습니다.**

### 6. 하단에 「전체는 설명란에」가 상시 떠 있다

마지막에 한 번 말하는 것과 다릅니다. 30초 내내 자리를 지킵니다.

### 7. 세로 화면의 자연스러운 동작은 세로 이동이다

화면보다 긴 지면을 카메라가 위아래로 옮겨 갑니다. 좌우로 늘어놓으면 세로 화면에서
좌우가 헐거워집니다.
